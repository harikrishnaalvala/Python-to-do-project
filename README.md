# 📝 Python To-Do List Application

A simple command-line To-Do List application built using Python. This project allows users to add, view, and delete tasks through an interactive menu-driven interface.

---

## 🚀 Features

- View all tasks
- Add new tasks
- Delete existing tasks
- Interactive CLI menu
- Exception handling for invalid inputs

---

## 🛠️ Technologies Used

- Python 3
- Lists
- Functions
- Loops
- Exception Handling

## ⚙️ Functionalities

### 1️⃣ View Tasks

Displays all the tasks currently stored.

Example:

```text
Your To-Do List:

1. Complete Python Assignment
2. Practice JavaScript
3. Build React Project
```

---

### 2️⃣ Add Task

Allows the user to add a new task.

Example:

```text
Enter the task to add:
Learn Data Structures

Task added successfully.
```

---

### 3️⃣ Delete Task

Displays all tasks and removes the selected task.

Example:

```text
Enter the task number to delete:
2

Task 'Practice JavaScript' deleted successfully.
```

If an invalid number is entered, the program displays an error message.

---

### 4️⃣ Exit

Terminates the application.

```text
Exiting the application. Goodbye!
```
